# Moretes
Modelo de Recomendação de Testes (Test Recommendation Model)


- Python 3.10+

First time:
`python -m venv venv`


Every new terminal tab (Windows):
`.\venv\Scripts\activate` 
Case error of Policy:
`Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser` 

On linux:
`./venv/bin/activate`


On new dependencies:
- `pip install -r requirements.txt`

Make .exe
- `.\venv\Scripts\activate` 
- `pyinstaller main.py --noconsole --onefile`
